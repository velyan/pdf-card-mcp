# Code Of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project respectful and harassment-free for everyone.

## Expected Behavior

- Be direct, constructive, and specific.
- Respect privacy, especially around PDFs, generated readers, notes, and highlights.
- Assume good intent while keeping technical claims grounded in evidence.

## Unacceptable Behavior

Harassment, discriminatory language, threats, doxxing, and publishing someone else's private
documents or annotations without permission are not acceptable.

## Enforcement

Project maintainers may remove comments, close issues, block users, or take other reasonable
action to keep the project safe and focused.
